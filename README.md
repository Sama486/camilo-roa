# Camilo Roa — Personal Trainer Website

Statische, „innovative" One-Page-Website für den Personal Trainer **Camilo Roa**
([@camiloor05](https://www.instagram.com/camiloor05/)).

## Design
Dunkel, hochkontrastig, athletisch — schwarzer Hintergrund, kräftige
kondensierte Versal-Typografie (Display „Bebas Neue" + Body „Inter") und **ein**
sparsamer roter Akzent (#e5342b), nur für Claim-Wörter, Index-Nummern und den
Featured-CTA. Camilos dunkle Gym-Fotos leuchten gegen das Schwarz. Leit-Claim
**„Nicht denken. Tun."** stammt aus seinem eigenen Post.

Orientiert an der Formel der besten Fitness-/Trainer-Websites (Awwwards & Co.):
schwarze Basis lässt die Trainingsfotos wirken, hoher S/W-Kontrast, fette
kondensierte Sans (Bebas/Oswald-Stil), genau ein energetischer Akzent, kurze
harte Copy. Farbakzent (Rot) vom Kunden gewählt.

## Öffnen
Einfach `index.html` im Browser öffnen. Keine Build-Tools, kein Server nötig.
(Google Fonts werden online geladen; ohne Internet greifen System-Fallbacks.)

## Struktur
```
camilo-roa/
├─ index.html      # Inhalt & Sektionen
├─ styles.css      # Dark-Cinematic-Design
├─ script.js       # Scroll-Progress, Text-Scramble, Counter, horizontale Pin-Sektion
└─ assets/         # Echte Bilder aus seinem Instagram
   ├─ post.jpg     # Hero-Portrait
   ├─ hero.jpg     # Über-mich-Bild
   └─ camilo.jpg   # Profilbild
```

## Interaktions-Regel
Hover-Effekte gibt es **nur** auf tatsächlich klickbaren Elementen (Buttons,
Nav-Links, Social-Links). Dekorative Karten, Bilder und das Marquee haben
bewusst **keine** Hover-Effekte.
